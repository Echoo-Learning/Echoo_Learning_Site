# Echoo_Learning_Site

忆可学境(Echoo Learning)**开发测试环境**的公开网页(GitHub Pages)。

- 公网地址:https://echoo-learning.github.io/Echoo_Learning_Site/
- 状态:搭建中,仅用于开发测试,不是正式产品,不含真实学生数据。

这个仓库只放"生成好的静态网页 + 测试数据",**不含任何密钥**。源码在私有仓库 `Echoo-Learning/Echoo_Learning`,
由 `tools/set-env.py` 渲染后发布到这里:

| 子目录 | 内容 |
|---|---|
| `anki/` | 网页 Anki(学生背词页、老师登录版本) |
| `lookup/` | 查词(标生词页面、老师登录版本) |
| `det/` | 多邻国(DET)练习 |
